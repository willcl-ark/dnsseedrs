Method

Attempted addresses are rows present in the dump; the dump excludes untried database rows. Contacted means a successful version handshake has been recorded. Good means eligible for seeding. No handshake means attempts have not completed a version handshake; it does not mean untried. User agents with a Satoshi: product token are classified as Bitcoin Core; all other reported user agents are grouped as Other.
